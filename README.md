**Интерактивная платформа для обучения менеджеров экологичной обратной связи**

## 🌐 [Открыть сайт](https://managertutor.streamlit.app/)

---

## 📋 Описание проекта

ManagerTutor — это образовательная платформа, которая помогает менеджерам и руководителям научиться давать конструктивную, экологичную обратную связь своим сотрудникам. Платформа использует современные фреймворки коммуникации (SBI, Radical Candor, BOFF, NVC, GROW) и ИИ-агентов для создания реалистичных симуляций разговоров.

### Ключевые особенности:
- 🎓 **6 структурированных уроков** по проверенным методикам обратной связи
- 🤖 **ИИ-сотрудники** с различными типами личности (скептичный, защищающийся, скромный и т.д.)
- 📊 **Автоматическая оценка** навыков по 5 метрикам с детальной обратной связью
- 💬 **Чат с ИИ-ментором** для получения персональных советов
- 📱 **Telegram-бот** для доступа к ментору в любое время
- 📈 **Система прогресса** с отслеживанием достижений

---

## 💡 Решение

ManagerTutor предлагает практическое обучение через:

1. **Теоретическую базу** — изучение проверенных методик с примерами
2. **Практику с ИИ** — симуляция реальных разговоров с сотрудниками
3. **Объективную оценку** — анализ навыков по конкретным метрикам
4. **Персонального ментора** — помощь в решении реальных ситуаций

## 🏗️ Архитектура

### Стек технологий:
- **Frontend:** Streamlit (веб-интерфейс)
- **Backend:** Python 3.11+
- **LLM:** Mistral AI (mistral-small-latest)
- **Framework:** LangChain (управление диалогами и памятью)
- **Bot:** Aiogram 3.x (Telegram-бот)

### Компоненты:

```
├── llm_agents/                 # ИИ-агенты
│   ├── role_agent.py          # Агент-сотрудник для практики
│   ├── evaluation_agent.py    # Агент-оценщик навыков
│   ├── mentor_agent.py        # Агент-ментор для консультаций
│   └── prompts/               # Системные промпты
├── lessons/                    # JSON-файлы с уроками
├── mentor_bot/                 # Telegram-бот
│   └── tg_bot.py              
├── main.py                     # Streamlit приложение
└── requirements.txt
```

### Ключевые агенты:

**1. RoleAgent (Агент-сотрудник)**
- Симулирует реального сотрудника с определенным типом личности
- Использует `ConversationBufferMemory` для сохранения контекста диалога
- Температура: 0.8 (более естественные, живые ответы)

**2. EvaluationAgent (Агент-оценщик)**
- Анализирует диалог менеджера с сотрудником
- Оценивает по 5 метрикам: конкретность, структура, эмпатия, действенность, своевременность
- Температура: 0.3 (более консистентная оценка)
- Возвращает структурированный JSON с баллами и рекомендациями

**3. MentorAgent (Агент-ментор)**
- Консультирует по реальным ситуациям
- Доступен через веб-интерфейс и Telegram
- Дает конкретные примеры и пошаговые советы

## 📚 Уроки

### 1. **SBI: Ситуация-Поведение-Влияние** 🟢
Базовая модель для структурированной обратной связи

### 2. **BOFF: Поведение-Результат-Чувства-Будущее** 🟡
Фокус на эмоциях и будущих действиях

### 3. **Radical Candor: Забота + Честность** 🔴
Баланс между прямотой и эмпатией (Kim Scott)

### 4. **NVC: Ненасильственное общение** 🔴
Коммуникация без конфликтов (Marshall Rosenberg)

### 5. **GROW: Коучинговая модель** 🟡
Помощь сотрудникам находить решения самостоятельно

### 6. **Модель "Бутерброда"** 🟢
Классическая техника: позитив → критика → позитив

## 🎮 Как использовать

### Веб-интерфейс:

1. **Главная страница** — посмотрите свой прогресс и выберите действие
2. **Уроки** — выберите урок, изучите теорию, попрактикуйтесь с ИИ-сотрудником
3. **Практика** — общайтесь с ИИ-сотрудником, применяя изученную модель
4. **Результаты** — получите детальную оценку и рекомендации
5. **Чат с ментором** — задайте вопрос о реальной ситуации
6. **Глоссарий** — справочная информация по моделям
7. **Прогресс** — отслеживайте свои достижения

### Telegram-бот:

1. Откройте бота по ссылке из интерфейса
2. Опишите вашу ситуацию
3. Получите конкретные рекомендации
4. Используйте `/menu` для дополнительных опций

## 📊 Метрики оценки

Каждый диалог оценивается по 5 критериям (0-10 баллов):

1. **Конкретность** — использование конкретных примеров вместо общих фраз
2. **Структура** — следование выбранному фреймворку (SBI, BOFF и т.д.)
3. **Эмпатия** — уважительный и заботливый тон
4. **Действенность** — наличие четких шагов для улучшения
5. **Своевременность** — уместность обратной связи в данной ситуации

**Итоговый балл:** сумма всех метрик × 2 (максимум 100)

## 🤖 Особенности ИИ-агентов

### Типы личности сотрудников:

- **skeptical** — скептичный, требует конкретики и примеров
- **defensive** — защищается, воспринимает критику на личный счет
- **modest** — скромный, преуменьшает свои достижения
- **open** — открыт к обратной связи, задает уточняющие вопросы
- **aggressive** — агрессивно реагирует, оспаривает авторитет

### Память и контекст:

- Агенты используют `InMemoryChatMessageHistory` для сохранения контекста
- История доступна на протяжении всего диалога
- Агенты реагируют на предыдущие сообщения и эволюцию разговора

### Безопасность:

Все промпты содержат критические правила:
- ❌ Никогда не давать советов, которые могут обидеть сотрудника
- ❌ Не рекомендовать установление жесткой иерархии
- ✅ Быть тактичным и толерантным
- ✅ Давать только экологичные советы
